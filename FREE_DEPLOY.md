# Бесплатный деплой SPAXRIZE

Инструкция по запуску бота без оплаты. Все варианты имеют ограничения.

## Вариант 1: Render.com (БЕСПЛАТНО, но с ограничениями)

**Плюсы:**
- Полностью бесплатно
- Не нужна кредитка
- Простота деплоя

**Минусы:**
- Контейнер "спит" через 15 минут неактивности
- Просыпается при новом запросе (занимает 1-2 минуты)
- Может пропустить сообщения во время сна
- Ограничение: 750 часов/месяц

### Деплой на Render

1. **Создайте аккаунт на [render.com](https://render.com)**

2. **Подготовьте репозиторий**
   - Загрузите проект на GitHub
   - Убедитесь, что `.env` и `data/watcher_session.session` **НЕ** в git
   - Добавьте секреты в Render (см. ниже)

3. **Создайте Web Service**
   - Dashboard → New → Web Service
   - Connect GitHub репозиторий
   - Name: `spaxrize`
   - Runtime: `Python 3`
   - Build Command: `pip install -r requirements.txt && python generate_banner.py`
   - Start Command: `python main.py`

4. **Добавьте Environment Variables**
   - `API_ID` = ваш ID
   - `API_HASH` = ваш hash
   - `BOT_TOKEN` = ваш токен
   - `SESSION` = `watcher_session`
   - `LOG_LEVEL` = `INFO`
   - `PORT` = `8080` (обязательно для Render)
   - `PING_INTERVAL` = `300` (5 минут - интервал само-пинга)

5. **Авторизация через Render Shell**
   - После первого деплоя сервис упадёт (нет сессии)
   - Откройте Shell в Render
   - Запустите: `python auth.py`
   - Введите номер и код из Telegram
   - Перезапустите сервис

6. **Встроенный механизм анти-сна**
   - Бот имеет встроенный HTTP сервер на порту 8080
   - Endpoint `/health` отвечает "OK"
   - Бот автоматически пингует сам себя каждые 5 минут
   - Это поддерживает активность контейнера

7. **Дополнительный внешний пинг (опционально)**
   - Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com)
   - Добавьте новый monitor → Type: HTTP
   - URL: `https://ваш-сервис.onrender.com/health`
   - Interval: 5 минут
   - Это дополнительная страховка

### Вердикт: ЧАСТИЧНО ПОДХОДИТ
С встроенным анти-сном бот будет работать лучше, но Render всё равно может усыплять контейнер. Не 100% гарантия.

## Вариант 2: Railway.app (БЕСПЛАТНЫЙ КРЕДИТ)

**Плюсы:**
- $5 кредит бесплатно при регистрации
- Не спит (пока есть кредит)
- Простота деплоя

**Минусы:**
- После $5 нужно платить (~$5/мес)
- Кредит закончится примерно через 1 месяц

### Деплой на Railway

1. **Создайте аккаунт на [railway.app](https://railway.app)**

2. **Подключите проект**
   - New Project → Deploy from GitHub repo
   - Выберите репозиторий

3. **Настройте переменные**
   - Variables → Add:
     - `API_ID`
     - `API_HASH`
     - `BOT_TOKEN`
     - `SESSION`
     - `LOG_LEVEL`

4. **Авторизация**
   - Откройте терминал в Railway
   - `python auth.py`
   - Введите данные

### Вердикт: ВРЕМЕННОЕ РЕШЕНИЕ
Работает 1 месяц бесплатно, потом нужно платить.

## Вариант 3: Oracle Cloud Always Free (БЕСПЛАТНО НАВСЕГДА)

**Плюсы:**
- 2 VPS AMD бесплатно навсегда
- 24/7 работа без ограничений
- Не спит

**Минусы:**
- **Нужна кредитка для верификации** (деньги не списывают)
- Сложнее настройка

### Деплой на Oracle Cloud

1. **Регистрация на [oracle.com/cloud](https://oracle.com/cloud)**
   - Создайте бесплатный аккаунт Always Free
   - Добавьте кредитку (только для верификации)

2. **Создание VPS**
   - Dashboard → Create Instance
   - Name: `spaxrize`
   - Shape: `VM.Standard.E2.F1` (бесплатный)
   - Image: `Ubuntu 22.04`
   - SSH ключ: добавьте свой

3. **Подключение к VPS**
   ```bash
   ssh ubuntu@your-ip
   ```

4. **Установка Docker**
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```

5. **Деплой проекта**
   - См. инструкцию в `DEPLOY.md`
   - Используйте `docker-compose up -d`

### Вердикт: ЛУЧШИЙ БЕСПЛАТНЫЙ ВАРИАНТ
Работает 24/7 навсегда, если есть кредитка для верификации.

## Вариант 4: Replit (БЕСПЛАТНО, но спит)

**Плюсы:**
- Полностью бесплатно
- Онлайн IDE из коробки
- Не нужна кредитка

**Минусы:**
- Спит через 1 час неактивности
- Нужен "Always On" ($7/мес) для 24/7

2. **Import from GitHub**
   - Импортируйте репозиторий

3. **Secrets**
   - Tools → Secrets → Add:
     - `API_ID`
     - `API_HASH`
     - `BOT_TOKEN`

4. **Shell → авторизация**
   ```bash
   python auth.py
   ```

5. **Запуск**
   ```bash
   python main.py
   ```

### Вердикт: НЕ ПОДХОДИТ для 24/7

## Рекомендация

**Если есть кредитка (деньги не списывают):**
- Oracle Cloud Always Free — лучший вариант, 24/7 навсегда

**Если кредитки нет:**
- Render.com — бесплатно, но бот будет часто спять и пропускать сообщения
- Railway.app — 1 месяц бесплатно, потом нужно платить

**Альтернатива:**
- Оставьте бот на своём ПК, если он работает постоянно
- Используйте Windows Task Scheduler для автозапуска

## Честный вывод

По-настоящему бесплатного 24/7 хостинга без кредитки **НЕ СУЩЕСТВУЕТ**.

Все бесплатные варианты либо:
- Спят при неактивности (Render, Replit)
- Требуют кредитку для верификации (Oracle, Google)
- Имеют ограничение по времени (Railway, GitHub Codespaces)

Для надёжной работы 24/7 нужен платный VPS (~150₽/мес) или кредитка для Oracle Cloud.
