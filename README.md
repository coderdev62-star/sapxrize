# SPAXRIZE — Вотчер личных чатов Telegram

🩸 Бот следит за **личными чатами** Telegram-аккаунта и уведомляет в чат с ботом об удалённых и изменённых сообщениях.

## Возможности

- 🗑 **Восстановление удалённых сообщений** — присылает полный текст и фото удалённых сообщений
- ✏️ **Отслеживание редактирований** — показывает «Было / Стало» для изменённых сообщений
- 🔄 **Работа 24/7** — MTProto-клиент получает обновления даже при закрытом Telegram
- 💾 **Кэширование** — все личные сообщения сохраняются в SQLite
- 🩸 **Кровавый стиль** — уникальный баннер SPAXRIZESAVE

## Архитектура

Бот состоит из двух компонентов в одном процессе:

1. **MTProto-клиент (Telethon)** — получает ВСЕ обновления аккаунта в реальном времени
2. **Bot API бот (aiohttp)** — канал уведомлений и управление (команды, inline-кнопки)

## Установка

### Требования

- Python 3.11+
- Windows

### Шаги

1. **Клонируйте или скачайте проект**

2. **Создайте виртуальное окружение**
   ```bash
   python -m venv venv
   ```

3. **Активируйте виртуальное окружение**
   ```bash
   venv\Scripts\activate
   ```

4. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

5. **Настройте `.env`** (уже создан с кредами)
   ```ini
   API_ID=31576834
   API_HASH=ad6503561fd24c4161fecbef2d17e1c3
   BOT_TOKEN=8857311670:AAHC89KJO399SGZ3z6OYzwM-N3MmS8FWobE
   SESSION=watcher_session
   LOG_LEVEL=INFO
   ```

## Первый запуск и авторизация

При первом запуске Telethon запросит авторизацию:

```bash
python main.py
```

1. Введите номер телефона (с кодом страны, например: `+79991234567`)
2. Введите код подтверждения из Telegram
3. Если включён 2FA — введите пароль

После успешной авторизации сессия сохранится в `data/watcher_session.session` и повторный ввод не потребуется.

## Использование

### Активация

1. Откройте бота в Telegram
2. Нажмите `/start`
3. Нажмите кнопку **«🩸 Добавить в автоматизацию»**
4. Бот активирован и начал слежение

⚠️ **Важно:** Сообщения, написанные ДО активации, восстановить невозможно.

### Команды

- `/start` — активация (если не активен) или статус
- `/status` — статус бота, число сообщений в кэше, ID владельца
- `/test` — тестовое уведомление (проверка канала доставки)
- `/stop` — снять владельца, остановить слежение

Если ПК работает постоянно — используйте:

1. Откройте «Task Scheduler»
2. Create Task → Triggers → «At startup»

4. Settings → «Run whether user is logged on or not»

**Или используйте `pythonw.exe` для запуска без окна:**
```bash

```

## Ограничения Telegram

1. **Secret Chats** — MTProto не имеет доступа к секретным чатам, они не отслеживаются
2. **Время кэша** — `catch_up` догружает пропущенные апдейты только за ограниченное время (обычно ~24-48 часов)
3. **FloodWait** — бот уважает ограничения Telegram и не обходит их
4. **Только личные чаты** — группы и каналы игнорируются

## Безопасность

- `.env`, `*.session`, `data/` — в `.gitignore`
- Логи маскируют `BOT_TOKEN` и `API_HASH`
- Фото удаляются с диска после успешной отправки уведомления

## Логирование

Логи пишутся в:
- Консоль (при запуске с консолью)
- Файл `data/watcher.log`

Формат: `%(asctime)s [%(levelname)s] %(name)s: %(message)s`

## Устранение проблем

**«Пользователь не авторизован»**
- Запустите авторизацию повторно, удалите `data/watcher_session.session`

**Бот не присылает уведомления**
- Проверьте `/status` — активен ли бот
- Проверьте `/test` — работает ли канал доставки
- Убедитесь, что процесс запущен

**Ошибки FloodWait**
- Бот автоматически уважает ограничения, подождите несколько минут
